## 1. Focus error — `err-indirect-question-called`

**Pattern:** Putting the subject in the wrong place in “What is X called?”

**You said:** “What is, what is called the method that AnkiDroid uses”

**Natural:** “What's the method AnkiDroid uses called?” / “What's it called, the method AnkiDroid uses?”

**Rule:** In *what is X called?*, the thing you’re naming (X) sits between *is* and *called*. Don’t start with *what is called* + the thing.

**Practice (say or write):**

1. What's that feature called?
2. What's the method Anki uses called?
3. I forgot — what's this error called in English?
4. What's the tool we use for reviews called?
5. Do you know what's this pattern called? → Fix to: Do you know what this pattern is called?

## 2. Focus error — `err-teach-needs-object`

**Pattern:** Using *teach* without saying **who** you teach.

**You said:** “teach how to run the application”

**Natural:** “teach **them** how to run the application” / “show how to run the application”

**Rule:** *Teach* is usually transitive with a person: *teach someone (how) to do something*. If there is no person, prefer *show*, *explain*, or *cover*.

**Practice (say or write):**

1. Can you teach me how to run the application?
2. The bot will teach him the correct phrasing.
3. Don't just teach grammar — teach them natural examples.
4. She taught us how to commit and push.
5. Teach how to use Git. → Fix to: Teach them how to use Git. / Show how to use Git.

## 3. Focus error — `err-dangerous-errors`

**Pattern:** Calling mistakes “dangerous.”

**You said:** “the most dangerous errors”

**Natural:** “my most serious / biggest / most common mistakes”

**Rule:** In learning English, mistakes are *serious*, *major*, *common*, or *frequent* — not *dangerous* (that word is for real risk: fire, traffic, etc.).

**Practice (say or write):**

1. Let's focus on my most serious mistakes.
2. Spaced repetition helps with the most common errors.
3. Grammar is my biggest problem right now.
4. Which mistakes are the most frequent in my sessions?
5. The most dangerous errors → Fix to: The most serious mistakes.
